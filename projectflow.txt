1. create a git repo and clone it in local
2. create a mycode.py and add code to it.(it will save a csv file to a new data folder)
3. Do a git commit push before initialize dvc.
4. #pip install dvc
5. Now we do "dvc init"
6. As of now just make 's3' folder(later on this will be replaced with actual aws s3 service)
7. Now we do "dvc remote add -d myremote s3"
8. Now "dvc add data/" (if you want to version any specific file under data folder do data/<filer name>)
       Now it will ask to do :("git rm -r --cached 'data'" and "git commit -m 'stop tracking data'")
       Because initially we track data/ folder from git so now we remove it for DVC to handle this . 
9. Again we do "dvc add data/" and then we do "git add .gitignore data.dvc"   
10. Do "dvc commit" and "dvc push"
